# AI Agent Development Ecosystem Monorepo

This monorepo contains the source code and resources for an advanced AI Agent Development Ecosystem, designed to be used with Visual Studio Code.

## Overview

The vision is to create a highly efficient, versatile, and developer-friendly environment for building, testing, and managing sophisticated AI agents and multi-agent systems. This ecosystem is particularly tailored to support agents like "Architect-Dominion Symbiont AI™" and its specialized execution cores.

Key components of this ecosystem include:

*   **AI Agent Definitions:** Standardized YAML definitions for AI agents, their capabilities, tools, and prompts.
*   **VS Code Core Extension (`ai-ecosystem-core`):** Provides the central tooling within VS Code for agent development, including agent definition management, prompt engineering utilities, and integration with agent logic.
*   **Shared Libraries:** Reusable code in Python and TypeScript to support agent tool development and VS Code extension functionalities.
*   **Code Generation Templates:** Templates for scaffolding new agents, agent tools, Dockerfiles, and other common components.
*   **Comprehensive Documentation:** Detailed guides for developers using and contributing to the ecosystem.

## Directory Structure

*   `/.jules/agents/`: Contains all AI agent YAML definitions.
*   `/docs/`: Documentation, including architecture, user guides, and contribution guidelines.
*   `/extensions/`: Source code for VS Code extensions, including the `ai-ecosystem-core`.
*   `/libraries/`: Shared Python and TypeScript libraries.
*   `/scripts/`: Utility scripts for managing the monorepo.
*   `/templates/`: Templates used for code generation.
*   `/tests/`: Automated tests for libraries and extensions.
